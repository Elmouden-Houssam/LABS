# Restaurant Management System

---

## 1. Project Subject

My project is a **Restaurant Management System**.

It is a web application that allows restaurant owners and staff to manage restaurant operations. It organizes information about menu items, categories, tables, orders, and customers.

---

## 2. Project Objective

The objective of this project is to simplify restaurant management and improve the organization of daily operations.

Users can:

- Manage menu items.
- Organize meals by category.
- Manage restaurant tables.
- Create and manage customer orders.
- Track order statuses.
- Manage customer information.
